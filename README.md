# Travel Tracker Site

Public static host for the Travel Tracker mobile PWA.

This repository contains generated Blazor WebAssembly publish output from the
private source repository. Do not edit the generated app files here directly;
publish from the private repository instead.

GitHub Pages URL:

https://working-order.github.io/Travel-Tracker-Site/

## Install on iPhone

Open the URL above in Safari, tap the share button, then choose
**Add to Home Screen**.
